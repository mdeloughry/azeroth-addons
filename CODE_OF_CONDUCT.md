# Community conduct

Treat contributors and testers with respect. Discuss code and behavior rather than attacking people. Explain disagreements with evidence; accept corrections and leave room for different experience levels.

Harassment, threats, discriminatory abuse, doxxing and sharing someone else's private data are not acceptable. Never post API credentials or unredacted device logs.

Maintainers may edit/remove harmful content, close discussions or restrict participation. Follow GitHub's abuse-reporting process for serious incidents; contact the maintainer privately when possible. If a private channel is not available, request one without publishing sensitive details.

This guidance applies to project issues, pull requests, testing reports and other project spaces.
